# SalaryTick

SalaryTick 是一款面向 Windows 的轻量实时工资计算工具。完成工资与标准作息设置后，程序会自动计算今日收入、工作时长和计薪加班。

日常使用以悬浮窗和系统托盘为主，主界面用于查看今日数据、本月概览及管理加班记录。工资和加班数据仅保存在当前 Windows 用户的本地目录，不会上传到网络。

SalaryTick 支持简体中文和 English。首次启动时会先选择界面语言。

## 1. 环境要求

- Windows 10 或 Windows 11
- Python 3.11 或更高版本
- Tkinter
- Pillow
- pystray

> 当前 `requirements.txt` 位于 `salary_tick` 目录中。请在项目根目录执行下面的安装命令，不要直接使用 `-r requirements.txt`。

## 2. 安装与启动

打开 PowerShell 或命令提示符，进入项目根目录：

```powershell
cd D:\tools\SalaryTick\SalaryTick
```

安装依赖：

```powershell
python -m pip install -r salary_tick\requirements.txt
```

启动程序：

```powershell
python main.py
```

启动后：

- 首次启动会先显示语言选择，然后进入工资和作息设置。
- 完成首次设置后，程序显示悬浮窗并创建系统托盘图标。
- 后续启动会直接恢复悬浮窗。
- 主界面默认隐藏，可从悬浮窗右键菜单或系统托盘打开。

## 3. 首次使用

首次设置分为三步。

### 第一步：选择语言

可选择：

- 简体中文
- English

选择后，后续向导立即使用所选语言。

### 第二步：设置工资信息

需要填写：

- 工资所属年月
- 月基本工资
- 月工作日
- 加班倍率

未勾选“手动修改工作日数”时，程序会根据内置工作日日历自动计算当月工作日。

### 第三步：设置标准作息

需要填写：

- 上班时间
- 午休开始时间
- 午休结束时间
- 正常下班时间
- 加班起算时间

正常下班至加班起算之间不计入工作时长和加班工资。

## 4. 日常使用

### 悬浮窗

悬浮窗显示：

- 今日收入
- 今日工作时长
- 金额显示／隐藏按钮

操作方式：

- 按住悬浮窗拖动，可在多个显示器之间移动。
- 程序会保存悬浮窗位置。
- 如果原显示器被断开，程序下次启动时会把悬浮窗恢复到主屏可见区域。
- 右键悬浮窗可打开快捷菜单。

### 悬浮窗右键菜单

菜单提供：

- 打开主界面
- 预计下班时间减 30 分钟
- 预计下班时间加 30 分钟
- 显示／隐藏金额
- 设置
- 本月加班明细
- 补录加班
- 退出程序

点击预计下班时间 `-30分钟` 或 `+30分钟` 后，菜单保持打开；点击其他项目或菜单外部时，菜单关闭。

### 系统托盘

系统托盘提供：

- 打开主界面
- 显示／隐藏金额
- 调整预计下班时间
- 打开设置
- 查看或补录加班
- 退出程序

如果任务栏右下角没有直接显示图标，请检查 Windows 的隐藏图标区域。

### 主界面

主界面显示：

- 当前工作状态
- 今日预计下班时间
- 今日工作时长
- 今日合计
- 本月基本工资
- 本月加班时长和估算金额

关闭主界面只会隐藏窗口，不会退出程序。真正退出请使用悬浮窗菜单或系统托盘中的“退出程序”。

### 加班记录

SalaryTick 支持：

- 自动记录当日计薪加班
- 手动补录加班
- 编辑已有记录
- 删除已有记录
- 覆盖同一天的已有记录

程序会区分自动记录、手动补录和手动修正。

## 5. 工资计算规则

- 上班前不计薪。
- 午休期间暂停累计。
- 正常下班至加班起算之间不计薪。
- 加班从“加班起算时间”开始计算。
- 加班最多计算到“今日预计下班时间”。
- 日工资按“月基本工资 ÷ 月工作日”计算。
- 加班工资按标准工作秒工资和加班倍率计算。
- 非当月数据不参与今日实时计算。
- 当前版本不支持跨午夜班次。

示例：

```text
上班时间：08:15
午休时间：11:45～12:45
正常下班：17:15
加班起算：17:45
预计下班：19:15

正常工作：8小时
计薪加班：1小时30分钟
合计工作：9小时30分钟
```

## 6. 隐私与数据显示

金额显示支持：

- 直接显示
- 默认隐藏，手动切换
- 始终隐藏

主界面与悬浮窗的金额显示可以分别控制。隐藏金额时，界面使用遮挡字符代替真实数值，但不会影响工资计算和本地保存。

SalaryTick 不连接考勤系统，不上传工资或加班信息，也不使用云同步。

## 7. 语言切换

打开：

```text
设置 → 显示设置 → 界面语言
```

选择：

- 简体中文
- English

点击“保存并应用”后退出并重新启动 SalaryTick，语言设置生效。

程序内部使用稳定语言代码：

```text
zh_CN
 en_US
```

## 8. 数据保存位置

数据默认保存在：

```text
%LOCALAPPDATA%\SalaryTick\
```

主要文件：

```text
settings.json
 overtime_records.json
```

其中：

- `settings.json` 保存工资、作息、语言、隐私设置和悬浮窗位置。
- `overtime_records.json` 保存加班记录。

设置与加班记录使用临时文件写入后再替换正式文件，减少写入中断导致 JSON 损坏的风险。

## 9. 运行测试

在项目根目录执行：


测试覆盖：

- 工资和加班计算
- 午休与加班等待时间
- 工作日和节假日
- 跨日、跨月和跨年处理
- 配置和加班记录存储
- 隐私状态规则
- 多显示器位置恢复
- 悬浮菜单定位
- 中英文翻译和字体选择

测试结果会写入：

```text
测试执行结果.txt
```

## 10. 常见问题

### 执行依赖安装命令时提示找不到 requirements.txt

确认在项目根目录执行：

```powershell
python -m pip install -r salary_tick\requirements.txt
```

### 托盘图标不显示

重新安装依赖：

```powershell
python -m pip install pystray Pillow
```

然后查看 Windows 任务栏右下角的隐藏图标区域。

### 找不到主界面

使用以下任一方式：

- 右键悬浮窗，选择“打开主界面”。
- 点击系统托盘中的 SalaryTick 图标并选择“打开主界面”。

### 想重新执行首次设置

SalaryTick 当前没有单独的“恢复首次设置”按钮。如需完全重置，请先退出程序，备份后删除：

```text
%LOCALAPPDATA%\SalaryTick\settings.json
```

下次启动时会重新进入首次设置向导。

| `overtime_store.py` | 加班记录保存 |
| `ui_styles.py` | 全局界面风格 |

## 12. 当前边界

当前版本不提供：

- 税费和社保计算
- 正式工资单
- 云同步
- 自动读取企业考勤
- 多套班次
- 跨午夜班次
- 自动更新
- 移动端版本

新增功能前应先确定范围，并为新增规则补充自动测试。
